# 🎨 DISM — Diseño de Interfaces en Sistemas Multimedia / Multimedia Interface Design

> **Grado en Ingeniería Multimedia — Universidad de Alicante (UA)**  
> **Autor / Author:** Leigh Garrett (@slg71)

---

### 📖 Descripción / Overview
🇪🇸 **ES:**  
Proyectos y prácticas de la asignatura **Diseño de Interfaces en Sistemas Multimedia (DISM)**. Centrado en la experiencia de usuario (**UX**), diseño de interfaces (**UI**), arquitectura de la información, accesibilidad web y prototipado interactivo aplicando principios de usabilidad centrados en el usuario.

🇬🇧 **EN:**  
Coursework and projects for **Multimedia Systems Interface Design (DISM)**. Focused on User Experience (**UX**), User Interface design (**UI**), information architecture, accessibility standards, and interactive frontend prototyping following user-centered design and usability principles.

---

### 🛠️ Tecnologías y Herramientas / Tech & Tools
- **Desarrollo e Interfaz:** HTML5, CSS3, JavaScript, TypeScript
- **conceptos clave / Key Concepts:** Diseño centrado en el usuario (UCD), Usabilidad, Accesibilidad, Responsive Design.
